SEO Automation Agent 

Overview

This project is an AI-powered SEO automation tool that generates optimized content based on user input keywords.

Features

- Keyword-based SEO content generation
- AI-generated title, meta description, keywords, and article
- Simple and clean React UI
- Node.js backend with API integration
- Groq API for fast AI content generation

Tech Stack

- Frontend: React.js
- Backend: Node.js (Express)
- AI: Groq API

How It Works

1. User enters a keyword
2. Frontend sends request to backend
3. Backend calls Groq API
4. AI generates SEO content
5. Content is displayed in UI


Setup Instructions

1. Clone the repo
2. Install dependencies:
   - cd backend → npm install
   - cd frontend → npm install
3. Add your Groq API key in backend
4. Run backend: node server.js
5. Run frontend: npm start
